# Eva Admin Frontend

پنل خصوصی مدیریت Meet Eva است و به‌صورت برنامه‌ای مستقل از سایت کاربران منتشر می‌شود. ظاهر راست‌چین، فونت، رنگ‌ها و کامپوننت‌های HeroUI با فرانت اصلی هماهنگ شده‌اند.

## محل اجرا

برنامه روی همان سرور Docker ایوا و در کانتینر جدا اجرا می‌شود. نشانی عمومی آن `admin.meeteva.ir` است؛ Caddy درخواست را به پنل می‌فرستد و پنل از شبکهٔ داخلی Docker به API ادمین بک‌اند وصل می‌شود. مرورگر هیچ‌وقت `ADMIN_API_KEY` را دریافت نمی‌کند. برای محافظت بیشتر، روی hostname پنل در Cloudflare Access فقط ایمیل مدیر را مجاز کن و MFA را روشن کن.

کد این پروژه، وابستگی‌هایش و انتشارش مستقل است. تنظیم hostname در Caddy و افزودن سرویس به Compose در مخزن بک‌اند می‌ماند چون همان‌جا تنظیمات سرور ایوا نگهداری می‌شود.

## رازهای لازم روی سرور

در فایل `/opt/eva/.env` این مقادیر را بگذار (رمزها را در Git ذخیره نکن):

```dotenv
ADMIN_API_KEY=یک-کلید-تصادفی-حداقل-۳۲-کاراکتری
ADMIN_DASHBOARD_PASSWORD=یک-رمز-ورود-تصادفی-حداقل-۱۶-کاراکتری
ADMIN_SESSION_SECRET=یک-راز-تصادفی-حداقل-۳۲-کاراکتری
```

همین `ADMIN_API_KEY` باید در backend باشد. برای ساخت مقادیر تصادفی:

```bash
openssl rand -hex 32
```

## اجرای محلی

```bash
npm ci
cp .env.example .env.local
npm run dev
```

برای اتصال محلی، `ADMIN_API_BASE_URL` و `ADMIN_BACKEND_URL` را روی آدرس بک‌اند بگذار. ساخت تصویر مستقل:

```bash
docker build -t eva-admin-front .
```

## انتشار

مخزن خصوصی `eva-admin-front` را در همان حساب GitHub ایوا بساز و این کد را به شاخهٔ `main` بفرست. GitHub Actions به‌صورت خودکار فرانت پنل را می‌سازد و در GHCR می‌گذارد. اگر بعداً بک‌اند مستقل برای پنل ساختیم، می‌توانیم آن را در مخزن جدا نگه داریم. بعد باید یک secret جداگانه به نام `EVA_ADMIN_PRODUCTION_ENV` به مخزن بک‌اند ایوا اضافه و تغییرات زیرساخت آن را منتشر کرد. نمونهٔ متن secret در `eva/deploy/admin.env.example` است. در آخر، Cloudflare DNS و Access تنظیم می‌شوند. ورود پنل هم رمز جداگانه دارد و نشست آن ۸ ساعت اعتبار دارد.

امکانات فعلی: نمای کلی کاربران/گفت‌وگوها/مصرف و هزینهٔ AI، نرخ `NO_REPLY`، میانگین زمان پاسخ، جدول مصرف بر اساس روز و مدل، و دانلود ZIP لاگ پرامپت. لاگ پرامپت ممکن است متن خصوصی گفت‌وگوها را داشته باشد؛ دسترسی و نگهداری آن را محدود کن.
